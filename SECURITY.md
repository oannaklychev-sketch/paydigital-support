# Безопасность

Об уязвимостях сообщайте автору сайта (ObeOne) лично, не через публичные issues.

Сайт статический: без сервера, форм, авторизации, cookies и счётчиков. Скрипты и стили загружаются только с самого сайта, внешние ресурсы ограничены шрифтами Google Fonts (Content-Security-Policy). Сайт работает только по HTTPS.
