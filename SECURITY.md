# Безопасность

## Как сообщить об уязвимости

Не создавайте публичный issue. Напишите напрямую: https://t.me/i_am_ObeOne — опишите проблему и шаги, чтобы её воспроизвести. Ответ — в течение нескольких дней.

## Что сделано на сайте

- Сайт статический: нет сервера, базы данных, форм, авторизации и cookies. Данные посетителей не собираются, счётчиков и трекеров нет.
- Content-Security-Policy: скрипты только с самого сайта, внешние ресурсы — только шрифты Google Fonts, формы и встраивание плагинов запрещены.
- Referrer-Policy `strict-origin-when-cross-origin`: при переходе по внешним ссылкам не передаётся полный адрес страницы.
- Все внешние ссылки открываются с `rel="noopener noreferrer"`.
- Работает только по HTTPS (GitHub Pages + `upgrade-insecure-requests`).
- В репозитории нет ключей, токенов и паролей.
